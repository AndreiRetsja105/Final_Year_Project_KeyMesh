# Reflective journal

One file per week, named by ISO week: `2026-W42.md`, `2026-W43.md`, ...
Written every week (same day, 15–20 min), committed to git so each entry
has a date. Model: Driscoll (What? / So what? / Now what?).

Rules for myself:
- "What?" = facts only. "So what?" = why, alternatives, what I learned.
- Problems and dead ends are the most valuable entries.
- Link every entry to evidence (commits, test output, screenshots).
- Record supervisor meetings: advice given and what I did with it.
- Record where I used AI tools and what I changed myself.
